# 🧩 10. Pipeline और Terraform का Relationship

यह distinction बहुत important है।

Terraform:

```text
WHAT infrastructure चाहिए?
```

```text

```

Example:

```text
Terraform
    ↓
"मुझे एक Resource Group चाहिए"
```

```text
Pipeline
    ↓
"यह Terraform code कब execute होगा?"
```

Agent:

```text
"मैं Terraform commands execute करूँगा।"
```

Service Connection:

```text
"मैं Azure authentication provide करूँगा।"
```

Azure:

```text
"मैं actual infrastructure create करूँगा।"
```

# 🔐 21. Authentication vs Authorization

यह सबसे important troubleshooting concept है।

### Authentication

```text
"तुम कौन हो?"
```

Example:

```text
WIF
 ↓
Entra ID
 ↓
Identity
```

### Authorization

```text
"तुम क्या कर सकते हो?"
```

Example:

```text
Identity
 ↓
Azure RBAC
 ↓
Contributor / Other Role
```

Final:

```text
Authentication
      ↓
      WHO?
      ↓
Authorization
      ↓
      WHAT CAN YOU DO?
```

# 🚨 22. अगर Authentication सफल लेकिन Authorization Fail हो?

Example:

```text
Pipeline
   ↓
Service Connection
   ↓
WIF
   ↓
Entra ID
   ↓
Authentication ✅
   ↓
Azure RBAC
   ↓
Authorization ❌
```

तब pipeline Azure तक पहुँच सकती है लेकिन resource operation नहीं कर पाएगी।

Possible error:

```text
AuthorizationFailed
```

इसलिए हर Azure DevOps engineer को यह distinction पता होना चाहिए।
